  - Deviations from the reference: (1) offsets are UTF-16 and `UTF16Map` is gone; a match that starts or ends inside a surrogate pair is not an occurrence, and `locate` never splits one. (2) Lower-casing is per code point (a whole-string `toLowerCase` makes the final sigma depend on the neighbours, so a snippet would not find itself), U+0130 becomes `i` as in Go. (3) Go's `json.Decoder` is emulated: the first value at a `{`, trailing text ignored, member names in any case, a wrong-typed field invalidates that object, `null` is empty. Lone surrogates in a JSON string become U+FFFD, as UTF-8 decoding does. (4) The error metadata is `reply_length` (Go: `reply_bytes`). (5) The reference records explanation usage only after a success; here, as §5.8 says, a failed or cancelled stream records what `onUsage` had reported. (6) The reference's `Model` (langchaingo, temperature, timeout) becomes `AnalysisModel` (client, name, timeout seconds, parallel); the temperature lives in the client configuration.
