Lone surrogates in a JSON string become U+FFFD, as UTF-8 decoding does. (4) The error metadata is `reply_length` (Go: `reply_bytes`). (5) The reference records explanation usage only after a success; here, as §5.8 says, a failed or cancelled stream records what `onUsage` had reported. (6) The reference's `Model` (langchaingo, temperature, timeout) becomes `AnalysisModel` (client, name, timeout seconds, parallel); the temperature lives in the client configuration.
