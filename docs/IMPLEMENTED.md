Lone surrogates in a JSON string become U+FFFD, as UTF-8 decoding does. (4) The error metadata is `reply_length` (Go: `reply_bytes`). (5) The reference records explanation usage only after a success; here, as §5.8 says, a failed or cancelled stream records what `onUsage` had reported. (6) The reference's `Model` (langchaingo, temperature, timeout) becomes `AnalysisModel` (client, name, timeout seconds, parallel); the temperature lives in the client configuration.   - Decisions: (1) A text that is only white space never counts as unsaved (no `*`, no question, no `beforeunload`), and Save, Save As and Save to library are disabled for it. (2) A library text is updated by Save to library without a title dialog (the title is changed with Rename), because "updates its document instead" reads that way and it keeps Save (a download) and the unsaved-changes dialog quick. (3) Save to library proposes the text's name if it has one (a file's name), otherwise the first non-blank line cut to 60 code points; the spec said the first line. (4) Save As does not rename a library document's text: otherwise the next Save to library would silently retitle the document with a file name. (5) A deleted document detaches the text but keeps its source key `doc:<old id>`, so the next Save to library moves those mistakes to the new document. (6) Lone `\r` line breaks become `\n` too (a textarea would do it anyway, and the text then equals the editor's value), and `crlf` is remembered when any `\r\n` is present. (7) "Has an extension" for `.txt` means a dot and one to four letters or digits at the end. (8) Download file names are sanitised (illegal characters, leading and trailing dots, length 120), because `downloads.download` refuses paths and `..`. (9) The tab state is written 400 ms after a change and when the page is hidden or unloaded, not on every key. (10) The tab's `sessionStorage` is the only restore: the editor has `autocomplete="off"`. (11) A check records under the source the tab has when it ends, not when it started, because Save to library can move the source meanwhile (a test covers it). (12) The message of `DocumentNotFound` became readable because the banner shows it. (13) `FileWriteFailed` has its own message ("The browser could not save the file."); the browser's message is only the `cause`. (14) The page's `loadText` ends a pending check with `discardCheck` (no "Check cancelled" after New), after `controller.cancel()`.
